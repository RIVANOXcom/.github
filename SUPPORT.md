
# RIVANOX Support

### Powerful Software. Practical by Design.

RIVANOX develops independent software solutions, focused SmartTools, Windows utilities, WordPress plugins, developer tools and specialized digital applications.

The focus is on reliable software, clear documentation and practical solutions for real-world digital workflows.

## Official Support

For technical assistance, product questions, installation issues, documentation feedback or licensing inquiries, visit:

**[RIVANOX Support](https://rivanox.com/support/)**

The official website provides current contact and support information.

## Preparing a Support Request

Where applicable, please include:

- Software or service name
- Installed version or release
- Operating system or technical environment
- WordPress version or browser details
- Description of the issue
- Expected and actual behavior
- Steps to reproduce the problem
- Relevant screenshots or sanitized logs

Confidential information, credentials, private code and license keys should never be published in public issues.

## Documentation & Licensing

Current information about software availability, licensing conditions and product documentation is published at:

**[RIVANOX.com](https://rivanox.com)**

Individual products and repositories may provide additional documentation or specific support conditions.

## Security Reports

Suspected security vulnerabilities should be reported privately according to SECURITY.md.

Public GitHub issues are not suitable for confidential vulnerability reports.
